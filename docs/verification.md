# Проверка программы — 18 ноября 2026 года

Проверена текущая промежуточная версия с заправкой **10 кг**, двумерным проигрывателем и одновременным показом четырёх сигналов. Среда: Python **3.12.14**, NumPy **2.3.5**, Matplotlib **3.10.8**, Linux, графический модуль **Agg**.

## Автоматические тесты

**39 тестов пройдены.** Протокол: [`results/test_results.txt`](../results/test_results.txt).

Проверяются траектория и добавки длины, рельеф, габаритные зазоры, ограничения движения, топливный и энергетический балансы, подбор заправки, плотность и вместимость, 24 канала датчиков, отказы GNSS, навигационные эталоны, двоичная запись и интерфейс. Добавлены проверки кнопок пуска, паузы, сброса и остановки в конце, а также различия топлива на маршруте и после посадки.

## Документация и целостность

Сборщик `scripts/build_report.py` выполнен в изолированной временной копии. Word и заметки успешно созданы, проверено наличие заправки 10 кг, массы 378 кг, резерва 0,300 кг и пяти имён. Текущие Word и презентация в репозитории не пересобирались. Числа в сборщике берутся из JSON, чтение явно использует UTF-8 для совместимости с Windows.

Проверены синтаксис Python, отсутствие ошибок `git diff --check`, русские комментарии и поясняющие строки, ссылки персональных памяток. Новый экран проигрывателя просмотрен после внеэкранного рендера.

## Повторение

```bash
python -m unittest discover -s tests -v
python scripts/verify_program.py
python scripts/check_fuel.py
python scripts/run_experiments.py
python -m compileall -q dtwin src scripts tests main.py
```

Проверка окна на пользовательском Windows, подключение реальных датчиков и натурная валидация двигателя в этот протокол не входят. Паспортная вместимость бака остаётся неизвестной и явно не считается подтверждённой проверкой миссии. GitHub Actions настроен на Python 3.11 и 3.12; этот локальный протокол относится к указанной выше среде.
