## Как части связаны

1. `config/mission.json` задаёт миссию и параметры, `config/sensors.json` — измерительные каналы.
2. Траектория и рельеф дают истинные координаты, скорость, ускорение и ориентацию по времени.
3. Энергетика добавляет мощность, топливо, массу и состояние батареи.
4. Датчики превращают истинное состояние в измерения с шумами и отказами.
5. Навигация оценивает движение по IMU и GNSS; истинная траектория нужна для подсчёта ошибки.
6. `simulation.py` собирает результаты, выполняет проверки, сохраняет JSON/CSV и телеметрию. Графики и проигрыватель показывают эти данные.

Общие соглашения: единицы СИ; мир ENU — X на восток, Y на север, Z вверх; корпус FLU — X вперёд, Y влево, Z вверх. Действующая программа находится в `dtwin/`; `src/model/` — исторические наработки.

## Общий запуск

```bash
python -m pip install -r requirements.txt
python -m dtwin replay results/reference
python -m unittest discover -s tests -v
python scripts/run_experiments.py
```

Текущая заправка — **10 кг**. Обоснование и ограничения: [перепроверка топлива](../fuel_review.md). Word и презентация пока относятся к предыдущей версии; для актуальных чисел используются `results/` и эти памятки.
